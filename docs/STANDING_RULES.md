1. At the start of every phase, read docs/MASTER_SPEC.md, docs/STANDING_RULES.md and docs/PHASE_LOG.md. Do only the current phase. Do not refactor earlier phases unless required to make checks pass.
2. Never ask questions. Log assumptions in docs/PHASE_LOG.md.
3. Every phase is done only when ALL pass: `npm run typecheck`, `npm run lint`, `npm run build` (zero errors, zero warnings); `npm run preview` serves the app; every new screen verified at 390x844 (and 1280x800 where specified) with screenshots saved to docs/screens/phase-N/; no console errors; no dead buttons; no placeholder text.
4. If a check fails, fix it and re-run. Never claim something works without having run it. If something cannot be finished, say so plainly in PHASE_LOG.md under "Known gaps".
5. Honesty: nothing in the UI claims more than it does. Simulated parts are listed in README under "Real vs simulated".
6. Offline: no runtime CDN, no Google Fonts links. Self-host all fonts via @fontsource packages (Inter, JetBrains Mono, Noto Sans Telugu and Devanagari subsets). The offline core (capture, processing, editing, export, search) makes ZERO network calls. The only allowed network calls are the optional opt-in sync/share endpoints and the one-time model download, all off by default and never on the capture or processing path.
7. Overrides to the master spec: (a) Web Speech API is optional, OFF by default, labelled "Online speech (uses your browser's speech service)"; when on, the offline badge must say so. (b) Telugu/Hindi text in PDFs is rasterised via canvas (browser shapes it correctly); Latin text stays real text. (c) Volume-button trigger is a UI setting with an honest browser-limitation note. (d) Biometric lock is WebAuthn if available, else clearly labelled simulated. (e) Web Share Target only works for the installed Android PWA; say so in the UI. (f) A browser cannot use the Snapdragon NPU; never claim NPU use. The web engine runs on WebGPU or WASM.
8. Code: strict TypeScript, no `any`, feature folders, design tokens only (no hardcoded hex in components), small components.
9. At the end of each phase: commit with message "phase N: <summary>" and append to docs/PHASE_LOG.md what was done, assumptions, and known gaps.
10. Backend (from Phase 7): the client works fully without it; every endpoint validates input with zod and is rate-limited; audio is never uploaded; secrets live only in env vars, never in client code or git.
